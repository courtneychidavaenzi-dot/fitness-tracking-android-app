# fitness-tracking-android-app
Android fitness tracking app built with Kotlin to log workouts and track progress with a clean user interface .Focused on responsive UI design and local data storage to improve user experience and app performance
# features
Track workouts, sets ,reps,squats
progress charts
Local data storage with Room
Clean material UI
# Tech Stack 
Kotlin, Jetpack Compose/ XML
# how to run
1.Clone repo
2.Open in android studio
3.Run on emulator or device

Download APK from releases section
